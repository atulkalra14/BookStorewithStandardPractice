# Book Store

An online book shopping app built with SAP CAP (Node.js) for SAP BTP.

- **Customers** browse the catalog and place orders for books.
- **Admin / shop owner** uses an internal app to manage books (genre, quantity, author and other book details) and authors (author name).

Technical conventions and workflow are in `CLAUDE.md`; domain notes and decisions go in `docs/`.

## Getting Started

```sh
npm ci
npx cds watch
```

See `CLAUDE.md` for all commands.
